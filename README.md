# SWYNEX-AI-Problem-Design

## 1. AI Problem Definition
The goal is to build a Sentiment Analysis System that automatically classifies user product reviews into "Positive" or "Negative" categories. This helps e-commerce platforms understand customer satisfaction instantly.

## 2. Target User
- E-commerce operations teams and customer support managers.

## 3. Data Source
- A small, open-source dataset containing 1,000 labeled customer reviews (text and sentiment labels).

## 4. Constraints
- The model must process text quickly.
- It must handle spelling mistakes or slang words commonly used in online reviews.

## 5. Success Criteria & Evaluation Approach
- **Success Criteria:** Achieve a minimum accuracy of 85% on the test data.
- **Evaluation Approach:** The dataset will be split into 80% for training and 20% for testing. We will use a Confusion Matrix (Precision, Recall, and F1-Score) to evaluate performance.
